# 発音の達人

プレイ中の「やり直す・速度変更」とリザルトの「速度を選んでもう一度」は、音声を止めて開始前の状態へ戻ります。選択中の速度を保持し、速度ボタンを強調します。新しい速度を選んでスタートを押すまで再生しません。

表示用画像はWebPへ軽量化済みです。背景は品質85、太鼓・バチ・英文枠は可逆圧縮とし、元PNGは保持しています。画面が読み込む画像5点の合計は2,275,921バイトから437,286バイトへ約81%削減しました。背景はHTMLから先行読み込みします。再生成は `sh scripts/optimize-assets.sh`（cwebpが必要）です。

HTML / CSS / バニラJavaScriptによる1英文のMVP。外部パッケージ・バックエンド・DBは不要です。

## 起動

Node.js 22以上で、このフォルダから実行します。

```sh
npm run dev
```

http://localhost:5173 を開きます。`npm install` は不要です。終了は Ctrl+C。
スマホは同じWi-Fiで `http://<PCのLAN IP>:5173` を開き、横向きにしてください。OSのファイアウォールで必要に応じて接続を許可します。

```sh
npm test
npm run build
```

`dist/` が静的配信用の成果物です。`file://` ではなくHTTPサーバーで開きます。

## 音声を用意した後

1. 自然な会話速度の米国英語による全文の録音を `public/audio/<ステージID>.mp3` に配置。
2. `src/stages.js` の各語の `start` に**元ファイル先頭からの発話開始秒**を設定。`null` のままでは開始不可。
3. 音声と時刻と分類を確認し `verified: true` に変更。
4. ステージを開き直し、実測済み音声へ自動で切り替わることと、各速度で音声と音符が一致することを実機確認。

音声は初回にデコードして先頭に2.5秒、末尾に0.4秒の無音を加え、PCM WAVをメモリ内で作成します。元ファイルは変更しません。単一のHTMLAudioElementがプリロールから音声本体まで担当します。`audio.currentTime - 2.5` が元音声の秒、描画はrequestAnimationFrame、実時間の判定差は `(現在時刻 - 発話時刻) / playbackRate` です。単語別setTimeoutはありません。

`preservesPitch` を指定しますが、特に0.25倍の音質とモバイルでの再生制約はブラウザ依存です。本番音声が無いため品質は未評価です。PCM化は短文向けで、長い音声にはメモリ負荷の改善が必要です。打撃効果音と音声は別出力経路なのでBluetooth等の遅延も実機調整してください。`RULES.offsetMs`（正値で遅めの入力を許容）は初期0です。

### 画像配信

画像は `public/assets/` を相対参照し、ビルド先でも同じフォルダ構成を保持します。開発サーバー固有の `/assets/` 変換に依存せず、通常の静的HTTPサーバーやサブディレクトリ配信でも太鼓とバチを読み込めます。`index.html` に画像の元サイズを明示し、CSSで縦横比と重なり順を指定しています。

## 合成音声の追加

`public/audio/stage-*-synthetic.wav` は米国英語Samanthaによる全文合成音声です。実測済み音声がない場合に自動で選ばれ、LISTENとプレイの両方で再生します。ガイド音は重ねません。

`src/synthetic-demo.js` に推定時刻、各ステージの `public/audio/stage-*-synthetic.json` に生成条件を保存します。本番用データは変更していません。時刻は各単語の単独発声長を全文の発声区間へ比例配分した推定値です。連結・強勢・ポーズの違いにより誤差があり、判定は動作確認用です。

macOSで `python3 scripts/generate-synthetic-audio.py` を実行すると全ステージを再生成できます。`--stage stage-02`を付けると指定ステージだけを生成します。追加パッケージ、外部API、APIキーは不要です。再生側は同梱WAVを使うためmacOSは不要です。実ブラウザでの音質・同期確認は未実施です。

音符は文字なし・赤青とも同径の丸に変更しました。英文は上部に固定表示し、音声時計に従って現在の単語をハイライトします。単語ラベルは将来の表示変更用にステージデータ内へ保持しています。
